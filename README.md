# Memória do Assistente IA (Smith) - Precisa Agrimensura

Este repositório contém as regras de negócio, histórico de erros e padrões de engenharia. O conhecimento consolidado está dividido em três arquivos mestres:

* **`MEMORIA_TERRAPLANAGEM.md`**: Regras de loteamento, M1 a M4, MDT, TIN, platôs, curvas de nível e correções de malha.
* **`MEMORIA_SANEAMENTO.md`**: Regras e dimensionamento de redes de Água, Esgoto e Drenagem, offsets, recobrimentos e pipeline automatizado.
* **`MEMORIA_PYQGIS_SMITH.md`**: Regras de comportamento do agente, restrições de permissão, tratamento de geometrias (DANI) e solução de bugs em PyQGIS.

**Instrução para a IA:** Não leia os três arquivos simultaneamente. Identifique o tema central da solicitação do usuário e consulte apenas o arquivo mestre correspondente para economizar contexto.
